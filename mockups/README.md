# Mockups

Static HTML exported from the Claude Design project. Each page is self-contained apart from React/Babel from unpkg and fonts from Google Fonts, so they work from any static host (GitHub Pages included) or by opening the file locally.

| File | What it is |
|---|---|
| `prototype.html` | Interactive flat simulation of the in-headset view. Click the stage once, then: `1–8` slot, `⌘K`/`Ctrl+K` finder, `F`/`D`/`W` mode, `←`/`→` rotate deck, hover a side pane to glance (0.7 s dwell pulls it forward), click to pinch. |
| `vision-deck.html` | 13-slide vision deck with speaker notes (text version in `../docs/vision.md`). |
| `readme-page.html` | Landing-page mockup. |
| `shots/` | Screenshots: `focus.jpg`, `deck.jpg`, `wall.jpg`. |
| `support.js`, `deck-stage.js` | Runtime for the pages above; not project code. |
